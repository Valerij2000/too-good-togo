# Вкусно. Выгодно. — Vite landing

Адаптивный концепт лендинга о сокращении пищевых отходов для Донецкой области. HTML, CSS и JavaScript без UI-фреймворков.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Перед публикацией

- Заменить демонстрационное название, тексты и изображения на утверждённый бренд-контент.
- Подключить форму `#join-form` к API/CRM/почте/боту. Сейчас форма только показывает демонстрационное уведомление и никуда не отправляет данные.
- Уточнить реальные города, партнёров, адреса, цены, условия выдачи и контактные данные.
- Добавить политику обработки персональных данных и согласие на обработку данных, если форма будет собирать реальные контакты.
- Для production лучше скачать изображения в `public/images`, оптимизировать их в AVIF/WebP и не зависеть от стороннего CDN.
- Проверить тексты и доступность на реальных устройствах.
